[h3]ENG[/h3]
Hi everyone!

[b]About the translation:[/b]
I'd like to share a multilingual translation patch for UnReal World 3.89.1.
Translation version: 0.25, released on 26 October 2026.

All enabled text entries in the prepared translation catalogue have their translation fields filled: 100% for Russian and Finnish. The main catalogues contain 15,850 and 15,849 enabled entries respectively, including messages, templates and their components. This measures catalogue completion; some messages may still appear in English during play. Overall in-game coverage has not been measured.

The translation was created using AI (Codex Pro, Astra). Human proofreading and editing are ongoing.
Russian and Finnish are currently available. French, German, Ukrainian, Japanese and Chinese are planned for the future.

Version 0.26 improves F2 quest-journal translation, quest-giver descriptions, herb quantities and long entries. Updates and Standard/Lite switching are available through the launcher.

[b]Installation:[/b]
1. Download the Standard or Lite archive.
2. Close the game. Extract its contents into the game folder containing urw.exe. If a previous translation is installed, allow the files to be overwritten.
3. Run URW_Launcher.exe and choose your language.

This release is intended for UnReal World 3.89.1. Hook 0.20 remains available for game version 3.89; Hook 0.19 is for 3.88.

[b]Standard vs Lite:[/b]
Both editions provide the same translation and launcher features.
Lite is suitable for playing and submitting bug-report logs. Standard also includes editing tools and files, including catalog.html and translations.csv.

Choose Lite if you just want to play. Download Standard if you'd like to proofread and edit the translation yourself.

[b]Automatic updates and edition selection:[/b]
In URW_Launcher.exe, click "Check for updates" to check the latest public release on GitHub. By default, Standard updates to Standard and Lite to Lite. To switch, select the other edition before checking; you can also switch within the same released version. No GitHub account is required; you need Windows PowerShell 5.1 and an Internet connection.
Confirm installation when offered. The updater verifies the archive and file checksums, retains URWTrace.ini settings, and refreshes the Steam loader if enabled. The game must be closed. Existing translation files, including your own edits, are replaced; one previous copy is saved in URW_update_backup. Save your own important edits elsewhere before another update replaces that backup. Switching to Lite removes only known editor files; unrelated files and game saves remain.
If an update fails, the updater attempts to roll back the changes. If the update is interrupted, the next update check first attempts to restore the previous files. Keep the backup and URW_update_pending.json until recovery finishes. Unknown game versions are refused.
After a manual ZIP update, click "Update Steam loader" if the launcher reports an outdated copy.

[b]How you can help:[/b]
Help with finding untranslated text, checking meaning and proofreading is very welcome. We especially need native Finnish speakers to proofread the Finnish translation.

1. Report untranslated words and sentences.
You can write them down and post them in this thread. Alternatively, enable "Write log" (LoggingEnabled = 1) in the launcher before starting the game. When you're finished, close the game, zip the relevant session folder inside logs, and send it to librianets@gmail.com or attach it here. If possible, include a few examples or a screenshot to help us locate the messages. Lite supports logging too.

2. Report translation problems.
If a sentence sounds unnatural, is grammatically incorrect or changes the meaning of the original, post it here. Suggested corrections are welcome.

You can also edit the text yourself:
— open rus_translate/catalog.html for Russian or fin_translate/catalog.html for Finnish;
— use the Open button to load the current catalog.json from the same folder;
— make your changes and click the button to save catalog.json;
— post the saved catalog.json here or send it by email.

3. Proofread the catalogue directly.
You don't have to play to help: open catalog.html for your language, load the current catalog.json, and work through the translation.

If you prefer a spreadsheet, edit translations.csv for your language in the Standard edition and send us the modified CSV. The game does not read CSV edits directly; they must be imported into the translation catalogue.

Please edit the translated text and its grammatical forms. Keep IDs, English source text, parameter names and control characters unchanged.

[b]Testing your changes in the game:[/b]
For the game to pick up your changes, the saved catalog.json must replace the file in rus_translate or fin_translate inside your game folder. If your browser saves it to Downloads, move it to the correct folder manually.

Most changes to ordinary messages are picked up while the game is running. Save the file, then trigger the message or dialogue again. You usually don't need to restart the game. Changes to the encyclopedia's index or searchable headings may require a restart.

If you can't find a message in the editor, or your change doesn't appear in the game, please report it here.

[b]Playing through Steam:[/b]
Close the game and open URW_Launcher.exe. In "Launch from Steam", select the game language and click "Change game language", then "Enable". From now on, use the normal Play button in Steam.
The original executable is preserved as urw-original.exe without changing its contents; our loader takes the name urw.exe. Its separate master copy, URWTrace.exe, stays in the folder.
All three direct ENG/RUS/FIN launch buttons are disabled while Steam mode is enabled. To change languages, close the game and use "Change game language". English starts the game without the translation hook. "Restore original" disables this mode and restores the direct launch buttons.

[b]After a Steam update or file verification:[/b]
If Steam restores its own urw.exe, close the game, install a compatible translation update and click "Repair after update". The new original replaces the saved original and the loader is copied back to urw.exe. A differing old original is retained under a name containing its checksum. Unknown game versions are refused until the translation is adapted.
"Restore original" never replaces a newer Steam EXE with an old backup. Do not manually delete URWSteam.state or urw-original.exe.

No GitHub account or registration is required to download a public release.

[h3]RUS[/h3]
Всем привет!

[b]О переводе:[/b]
Представляю многоязычный перевод UnReal World для версии игры 3.89.1.
Версия перевода: 0.25 от 26 октября 2026 года.

В подготовленном каталоге заполнены переводы всех включённых текстовых карточек: 100% для русского и финского языков. Основные каталоги содержат 15 850 и 15 849 включённые карточки соответственно: сообщения, шаблоны и их составные части. Это показатель заполненности каталога; в игре ещё могут встречаться английские сообщения. Общий охват всех игровых ситуаций пока не измерен.

Перевод выполнен с помощью нейросети (Codex Pro, Astra). Продолжаются ручная вычитка и редактирование текста.
Сейчас доступны русский и финский языки. В планах — французский, немецкий, украинский, японский и китайский.

В версии 0.26 исправлен перевод журнала заданий F2, описаний квестодателей, количества трав и длинных записей. Обновление и смена обычной версии/Lite доступны в лаунчере.

[b]Установка:[/b]
1. Скачайте архив: обычный или облегчённый (Lite).
2. Закройте игру. Распакуйте содержимое архива в папку игры, где находится urw.exe. Если перевод уже установлен, подтвердите замену файлов.
3. Запустите URW_Launcher.exe и выберите язык.

Этот выпуск предназначен для UnReal World 3.89.1. Для игры 3.89 доступен прежний Hook 0.20; для 3.88 — Hook 0.19.

[b]Чем обычная версия отличается от Lite:[/b]
Перевод и возможности запуска в обеих версиях одинаковые.
Lite подходит для игры и отправки журналов об ошибках. Обычная версия дополнительно содержит инструменты и файлы для редактирования перевода, в том числе catalog.html и translations.csv.

Если хотите только играть, выбирайте Lite. Если планируете вычитывать и самостоятельно редактировать перевод, скачайте обычную версию.

[b]Автообновление и выбор редакции:[/b]
В URW_Launcher.exe нажмите «Проверить обновления», чтобы проверить последний опубликованный релиз на GitHub. По умолчанию обычная редакция обновляется на обычную, Lite — на Lite. Для перехода выберите другую редакцию перед проверкой; это возможно и в пределах одной опубликованной версии. Нужны подключение к интернету и Windows PowerShell 5.1, учётная запись GitHub не требуется.
Подтвердите предложенную установку. Установщик проверит архив и контрольные суммы файлов, сохранит настройки URWTrace.ini и обновит копию загрузчика Steam, если этот режим включён. Игра должна быть закрыта. Файлы перевода, включая ваши правки, заменяются; одна предыдущая копия сохраняется в URW_update_backup. Важные собственные правки сохраните отдельно до следующего обновления, которое заменит эту резервную копию. При переходе на Lite удаляются только известные файлы редактора; посторонние файлы и сохранения игры остаются.
При ошибке выполняется попытка отката. Если обновление прервано, при следующей проверке обновлений установщик сначала пытается восстановить прежние файлы. Не удаляйте резервную копию и URW_update_pending.json до завершения восстановления. Неизвестная версия игры не принимается.
После ручного обновления через ZIP нажмите «Обновить загрузчик Steam», если лаунчер обнаружил старую копию.

[b]Как помочь с переводом:[/b]
Будем рады помощи с поиском пропусков, проверкой смысла и вычиткой. Особенно нужны носители финского языка для вычитки финского перевода.

1. Сообщайте о непереведённых словах и предложениях.
Можно выписывать их и отправлять сюда на форум. Другой вариант — перед запуском игры включить в лаунчере «Записывать журнал» (LoggingEnabled = 1). Закончив игру, закройте её и пришлите архив папки соответствующего запуска из logs на librianets@gmail.com или сюда на форум. По возможности добавьте несколько замеченных фраз или скриншот — так будет проще найти нужные сообщения. Для этого подходит и Lite.

2. Сообщайте о неудачных переводах.
Если фраза звучит неестественно, составлена неправильно или искажает смысл оригинала, отправьте её сюда на форум вместе с предлагаемым исправлением, если оно у вас есть.

Можно исправить текст самостоятельно:
— откройте rus_translate/catalog.html для русского или fin_translate/catalog.html для финского;
— через кнопку открытия загрузите актуальный catalog.json из той же папки;
— внесите правки и нажмите «Сохранить catalog.json»;
— пришлите сохранённый catalog.json на форум или на почту.

3. Вычитывайте каталог целиком.
Играть необязательно: можно открыть catalog.html нужного языка, загрузить актуальный catalog.json и последовательно проверять перевод.

Если удобнее работать с таблицей, отредактируйте translations.csv нужного языка из обычной редакции и пришлите изменённый CSV. Игра не читает правки CSV напрямую: их нужно импортировать в каталог перевода.

Редактируйте перевод и его словоформы. Не меняйте идентификаторы, английский исходник, имена параметров и управляющие символы.

[b]Проверка правок в игре:[/b]
Чтобы игра увидела изменения, сохранённый catalog.json должен заменить файл именно в rus_translate или fin_translate внутри папки игры. Если браузер просто скачал его в «Загрузки», перенесите файл вручную.

Большинство правок обычных сообщений подхватывается во время игры: сохраните файл и снова вызовите соответствующее сообщение или диалог. Перезапуск игры обычно не требуется. Для изменений индекса и поисковых заголовков энциклопедии может потребоваться перезапуск.

Если сообщения нет в редакторе или правка не появилась в игре, сообщите об этом на форум.

[b]Запуск через Steam:[/b]
Закройте игру и откройте URW_Launcher.exe. В блоке «Запуск из Steam» выберите язык игры, нажмите «Сменить язык игры», затем «Включить». После этого запускайте игру обычной кнопкой «Играть» в Steam.
Оригинальный EXE сохраняется как urw-original.exe без изменения содержимого, а наш загрузчик занимает место urw.exe. Отдельная копия загрузчика URWTrace.exe остаётся рядом.
Пока режим Steam включён, все три кнопки прямого запуска ENG/RUS/FIN заблокированы. Для смены языка закройте игру и используйте «Сменить язык игры». English запускает оригинал без хука перевода. Кнопка «Вернуть оригинальный запуск» отключает режим и возвращает прямые кнопки запуска.

[b]После обновления или проверки файлов Steam:[/b]
Если Steam восстановил свой urw.exe, закройте игру, установите совместимую версию перевода и нажмите «Восстановить после обновления». Новый оригинал сохраняется вместо прежнего, а загрузчик снова копируется на urw.exe. Отличающийся старый оригинал остаётся отдельно с контрольной суммой в имени. Неизвестная версия игры блокирует восстановление до адаптации перевода.
«Вернуть оригинальный запуск» не заменит новый EXE Steam старой резервной копией. Не удаляйте вручную URWSteam.state и urw-original.exe.
