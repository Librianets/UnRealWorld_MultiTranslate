[h3]ENG[/h3]
Hi everyone!

I'd like to share a multilingual translation patch for UnReal World 3.89.
Translation patch version: 0.20, as of 20 October 2026.

Our rough estimate puts translation coverage at around 99%. This does not mean every possible situation has been tested: some words and messages may still appear in English.

The translation was created using AI (Codex Pro, Astra). Human proofreading and editing are ongoing.
Russian and Finnish are currently available. French, German, Ukrainian, Japanese and Chinese are planned for the future.

We need native Finnish speakers to proofread the Finnish translation. If you'd like to help the community improve it, please get in touch!

[b]Download the translation:[/b]
[url=https://github.com/Librianets/UnRealWorld_MultiTranslate/releases/latest]GitHub Releases[/url]
[url=https://disk.yandex.ru/d/YopKMLmxCB1jKg]Yandex Disk[/url]

[b]Installation:[/b]
1. Download the latest translation archive, either Standard or Lite.
2. Extract its contents into the game folder containing urw.exe. If a previous translation is installed, allow the files to be overwritten.
3. Run URW_Launcher.exe and choose your language.

This release is intended for UnReal World 3.89.

[b]Standard vs Lite:[/b]
Both editions provide the same translation and launcher features.
Lite is suitable for playing and submitting bug-report logs. Standard also includes the translation catalogues and editing tools, including catalog.html and translations.csv.

Choose Lite if you just want to play. Download Standard if you'd like to proofread and edit the translation yourself.

[b]How you can help:[/b]
Help with finding untranslated text, checking meaning and proofreading is very welcome.

1. Report untranslated words and sentences.
You can write them down and post them in this thread. Alternatively, enable "Write log" (LoggingEnabled = 1) in the launcher before starting the game. When you're finished, close the game, zip the relevant session folder inside logs, and send it to librianets@gmail.com or attach it here. If possible, include a few examples or a screenshot to help us locate the messages. Lite supports logging too.

2. Report translation problems.
If a sentence sounds unnatural, is grammatically incorrect or changes the meaning of the original, post it here. Suggested corrections are welcome.

You can also edit the text yourself:
— open rus_translate/catalog.html for Russian or fin_translate/catalog.html for Finnish;
— use the Open button to load the current catalog.json from the same folder;
— make your changes and click the button to save catalog.json;
— post the saved catalog.json here or send it by email.

3. Proofread the catalogue directly.
You don't have to play to help: open catalog.html for your language, load the current catalog.json, and work through the translation.

Please edit the translated text and its grammatical forms. Keep IDs, English source text, parameter names and control characters unchanged.

[b]Testing your changes in the game:[/b]
For the game to pick up your changes, the saved catalog.json must replace the file in rus_translate or fin_translate inside your game folder. If your browser saves it to Downloads, move it to the correct folder manually.

Most changes to ordinary messages are picked up while the game is running. Save the file, then trigger the message or dialogue again. You usually don't need to restart the game. Changes to the encyclopedia's index or searchable headings may require a restart.

If you can't find a message in the editor, or your change doesn't appear in the game, please report it here.

[b]How to download from GitHub:[/b]
No GitHub account or registration is required to download the public release.
1. Open [url=https://github.com/Librianets/UnRealWorld_MultiTranslate/releases/latest]the latest release[/url]. At the moment, it is Hook 0.20 for UnReal World 3.89. Check that the release supports your game version.
2. Scroll down to Assets; expand the list if it is collapsed.
3. For playing, click Hook_0.20_lite.zip. For playing and proofreading/editing, click Hook_0.20.zip. Download one of these archives; both include Russian and Finnish.
4. Extract its contents into the game folder beside urw.exe, then run URW_Launcher.exe.

The automatically generated Source code (zip) and Source code (tar.gz) downloads contain repository sources, not the ready-to-play patch. SHA256SUMS.txt contains download checksums and is optional for playing.

[b]What the three GitHub repositories contain:[/b]
[url=https://github.com/Librianets/UnRealWorld_MultiTranslate]UnRealWorld_MultiTranslate[/url] — ready-to-play archives in Releases, Russian/Finnish catalogues, offline translation editor and packaging tools. This is the main project for players and translators.
[url=https://github.com/Librianets/UnRealWorld_Launcher]UnRealWorld_Launcher[/url] — source code for the launcher and its language/settings interface.
[url=https://github.com/Librianets/UnRealWorld_HookTranslate]UnRealWorld_HookTranslate[/url] — source code for the translation loader and hook, build instructions and tests.

Players do not need to download or build all three repositories. One Standard or Lite archive from the main project's Releases is sufficient; the original game is still required.

[h3]RUS[/h3]
Всем привет!

Представляю многоязычный перевод UnReal World для версии игры 3.89.
Версия перевода: 0.20, по состоянию на 20 октября 2026 года.

Охват перевода, по приблизительной оценке проекта, составляет около 99%. Это не означает, что проверены все игровые ситуации: отдельные слова и сообщения ещё могут оставаться на английском.

Перевод выполнен с помощью нейросети (Codex Pro, Astra). Продолжаются ручная вычитка и редактирование текста.
Сейчас доступны русский и финский языки. В планах — французский, немецкий, украинский, японский и китайский.

Для вычитки финского перевода нужны носители языка. Если хотите помочь сообществу улучшить его качество, пожалуйста, отзовитесь!

[b]Скачать перевод:[/b]
[url=https://github.com/Librianets/UnRealWorld_MultiTranslate/releases/latest]GitHub Releases[/url]
[url=https://disk.yandex.ru/d/YopKMLmxCB1jKg]Яндекс Диск[/url]

[b]Установка:[/b]
1. Скачайте архив последней версии перевода: обычный или облегчённый (Lite).
2. Распакуйте содержимое архива в папку игры, где находится urw.exe. Если перевод уже установлен, подтвердите замену файлов.
3. Запустите URW_Launcher.exe и выберите язык.

Этот выпуск предназначен для UnReal World 3.89.

[b]Чем обычная версия отличается от Lite:[/b]
Перевод и возможности запуска в обеих версиях одинаковые.
Lite подходит для игры и отправки журналов об ошибках. Обычная версия дополнительно содержит каталоги для редактирования перевода, в том числе catalog.html и translations.csv.

Если хотите только играть, выбирайте Lite. Если планируете вычитывать и самостоятельно редактировать перевод, скачайте обычную версию.

[b]Как помочь с переводом:[/b]
Будем рады помощи с поиском пропусков, проверкой смысла и вычиткой.

1. Сообщайте о непереведённых словах и предложениях.
Можно выписывать их и отправлять сюда на форум. Другой вариант — перед запуском игры включить в лаунчере «Записывать журнал» (LoggingEnabled = 1). Закончив игру, закройте её и пришлите архив папки соответствующего запуска из logs на librianets@gmail.com или сюда на форум. По возможности добавьте несколько замеченных фраз или скриншот — так будет проще найти нужные сообщения. Для этого подходит и Lite.

2. Сообщайте о неудачных переводах.
Если фраза звучит неестественно, составлена неправильно или искажает смысл оригинала, отправьте её сюда на форум вместе с предлагаемым исправлением, если оно у вас есть.

Можно исправить текст самостоятельно:
— откройте rus_translate/catalog.html для русского или fin_translate/catalog.html для финского;
— через кнопку открытия загрузите актуальный catalog.json из той же папки;
— внесите правки и нажмите «Сохранить catalog.json»;
— пришлите сохранённый catalog.json на форум или на почту.

3. Вычитывайте каталог целиком.
Играть необязательно: можно открыть catalog.html нужного языка, загрузить актуальный catalog.json и последовательно проверять перевод.

Редактируйте перевод и его словоформы. Не меняйте идентификаторы, английский исходник, имена параметров и управляющие символы.

[b]Проверка правок в игре:[/b]
Чтобы игра увидела изменения, сохранённый catalog.json должен заменить файл именно в rus_translate или fin_translate внутри папки игры. Если браузер просто скачал его в «Загрузки», перенесите файл вручную.

Большинство правок обычных сообщений подхватываются во время игры: сохраните файл и снова вызовите соответствующее сообщение или диалог. Перезапуск игры обычно не требуется. Для изменений индекса и поисковых заголовков энциклопедии может потребоваться перезапуск.

Если сообщения нет в редакторе или правка не появилась в игре, сообщите об этом на форум.
