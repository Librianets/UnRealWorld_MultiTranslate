UnReal World3.89.1 — Hook0.24 — Russian / Finnish

INSTALLATION
Close the game. Extract the ZIP beside urw.exe, replacing older translation
files. Start URW_Launcher.exe and select a language. Standard and Lite provide
the same translation; Standard includes the HTML/CSV editor. Console and logs
are off by default. Enable logging in the launcher only when collecting reports.

STEAM
Choose a language under Launch from Steam, click Change game language and Enable.
The original is preserved as urw-original.exe; a copy of URWTrace.exe takes the
name urw.exe. Original executable bytes remain unchanged. Direct EN/RU/FI buttons
are disabled in this mode. Change language with the game closed, or use Restore
original. English runs without the translation DLL.
If Steam mode is already enabled, use Repair after update after installing this
package to refresh the loader copy. After a game update, obtain a compatible
translation first. Do not copy URWSteam.state or urw-original.exe from other PCs.

CHANGES
0.24 fixes linen/hemp/nettle yarn, including length suffixes and compound item
labels. Includes0.23 L descriptions (confirmed working by a player) and quoted
F2 journal blocks. Unknown spans remain English. Actual quest gameplay still
needs player verification; automated replay is not a full playthrough.

EDITING
Open the language's catalog.html, load catalog.json, edit and save the JSON back
to the same directory. Preserve IDs, source text, variables and control markers.
Most message edits reload automatically; encyclopedia indexing may need restart.

РУССКИЙ
Закройте игру и распакуйте ZIP в папку с urw.exe с заменой файлов перевода.
Запустите URW_Launcher.exe. Обычный и Lite дают одинаковый перевод; в обычном
есть редактор HTML/CSV. Консоль и журналы выключены, включаются в лаунчере.
Для Steam выберите язык в блоке «Запуск из Steam», нажмите «Сменить язык игры»,
затем «Включить». Если этот режим уже включён, после обновления пакета нажмите
«Восстановить после обновления». Оригинал сохраняется как urw-original.exe;
его байты не меняются. На месте urw.exe запускается копия нашего загрузчика.
Отключение режима: «Вернуть оригинальный запуск». Не удаляйте URWSteam.state.
